# itpy Proftest

Рабочая версия 0.2 профориентационного теста для учеников 8–9 классов. Проект построен на Next.js App Router и готов к размещению на Vercel.

## Что уже работает

- стартовая страница;
- необязательное имя, класс, опыт и IT-интересы;
- анкета из 19 утверждений, включая обратные вопросы;
- 10 практических заданий с постепенным усложнением;
- 7 заданий с самостоятельным вводом ответа и 3 задания с выбором;
- 6 заданий с чтением Python-кода;
- повторные попытки, подсказки и разборы;
- автоматический расчёт 6 основных показателей;
- отдельные индексы ОГЭ и ЕГЭ;
- автоматический выбор одного из 7 итоговых профилей;
- версия заключения для ученика и родителя;
- печать / сохранение результата в PDF;
- сохранение прогресса в `localStorage`;
- необязательное сохранение результатов в Supabase и постоянные ссылки.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`.

Без Supabase сайт полностью работает, но не создаёт постоянную ссылку на результат.

## Подключение Supabase

1. Создайте проект Supabase.
2. Выполните SQL из `supabase/schema.sql` в SQL Editor.
3. Скопируйте `.env.example` в `.env.local`.
4. Заполните:

```env
NEXT_PUBLIC_SITE_URL=http://localhost:3000
SUPABASE_URL=https://YOUR_PROJECT.supabase.co
SUPABASE_SERVICE_ROLE_KEY=YOUR_SERVICE_ROLE_KEY
```

`SUPABASE_SERVICE_ROLE_KEY` нельзя публиковать и нельзя добавлять в переменную с префиксом `NEXT_PUBLIC_`.

## Размещение на Vercel

1. Загрузите папку проекта в GitHub.
2. В Vercel выберите **Add New → Project** и импортируйте репозиторий.
3. Добавьте переменные окружения, если используется Supabase.
4. Нажмите **Deploy**.

Можно также установить Vercel CLI и выполнить:

```bash
npm i -g vercel
vercel --prod
```

## Основные файлы

- `lib/questions.ts` — анкета и практические задания, ответы, подсказки и разборы;
- `lib/scoring.ts` — формулы, веса, индексы и выбор профиля;
- `lib/profiles.ts` — тексты итоговых профилей;
- `components/TestApp.tsx` — логика прохождения и проверка разных типов ответа;
- `components/ResultView.tsx` — итоговая страница;
- `app/globals.css` — оформление;
- `supabase/schema.sql` — таблица результатов.

## Важно перед публичным запуском

Текущие веса и пороги являются методическим прототипом. Перед использованием результата как устойчивой рекомендации нужно провести пилотирование минимум на 20–30 учениках, проверить распределение профилей и скорректировать границы.

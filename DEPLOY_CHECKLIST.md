# Чек-лист публикации

- [ ] Создать репозиторий GitHub и загрузить проект.
- [ ] Импортировать репозиторий в Vercel.
- [ ] Убедиться, что Vercel распознал Next.js.
- [ ] При необходимости создать Supabase и выполнить `supabase/schema.sql`.
- [ ] Добавить `SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` в Environment Variables Vercel.
- [ ] Задать `NEXT_PUBLIC_SITE_URL` равным публичному адресу сайта.
- [ ] Проверить тест на телефоне и компьютере.
- [ ] Подключить домен, например `test.itpy.ru`.
- [ ] Провести пилотирование на 20–30 учениках до активного продвижения.

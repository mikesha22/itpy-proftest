# Изменения версии 0.2

## Практический блок

- Полностью заменены 10 практических заданий.
- Добавлено постепенное усложнение от простого алгоритма до цикла с условием.
- 7 заданий теперь принимают самостоятельный ввод ответа.
- 3 задания оставлены в формате выбора варианта.
- В 6 заданиях используется Python-код.
- Задание 9 заменено на трассировку цикла с условием.

## Код проекта

- `lib/types.ts`: добавлены два типа практических заданий — `choice` и `input`.
- `components/TestApp.tsx`: добавлены ручной ввод, нормализация числовых ответов, отправка по Enter и отображение кода.
- `lib/scoring.ts`: группы логики, внимательности и кода теперь определяются по флагам заданий, а не по жёсткому списку номеров.
- `app/globals.css`: добавлены стили блока кода и поля ввода.
- Новый прогресс хранится в `itpy-proftest-progress-v0.2`, поэтому старое сохранение не ломает прохождение.
- API принимает результаты версий 0.1 и 0.2.
